# Архитектура операционных систем: пособие к экзамену

Пособие для подготовки к экзамену по дисциплине «Архитектура операционных систем» (специальность переподготовки 1-40 01 73 «Программное обеспечение информационных систем»). Сайт адаптирован для просмотра с телефона.

**Сайт:** https://ilsoft-dev.github.io/AOS-Exam/

## Что внутри

- **40 экзаменационных вопросов** (`q/01.md` … `q/40.md`). Каждый ответ начинается с блока «Коротко для ответа» и заканчивается вопросами для самопроверки.
- **Тест для самопроверки** (`quiz.md`, банк вопросов в `assets/quiz-data.js`).
- **Шпаргалка по командам Windows** для лабораторных работ (`cmd.md`).
- **Тупики (deadlocks)**: тема 8 программы (`extra/deadlocks.md`).
- **Глоссарий** (`glossary.md`).

Функции для телефона: оглавление в выдвижной панели, светлая и тёмная тема, изменение размера шрифта, отметки «выучено» с прогрессом на главной (хранятся в браузере), поиск по вопросам и терминам.

## Публикация на GitHub Pages

1. **Settings → Pages**.
2. **Source:** *Deploy from a branch*, ветка `main`, папка `/ (root)`.
3. Через минуту-две сайт будет доступен по адресу `https://<владелец>.github.io/AOS-Exam/`.

GitHub Pages сам собирает сайт с помощью Jekyll, поэтому отдельная сборка не нужна. Если репозиторий переименуют, поменяйте `baseurl` в `_config.yml`.

## Как редактировать

- Текст ответов — обычный Markdown в папке `q/`. Специальные блоки оформляются так:
  ```html
  <div class="tldr" markdown="1"> … </div>   <!-- «Коротко для ответа» -->
  <div class="exam" markdown="1"> … </div>   <!-- «Что спросят» -->
  <div class="tip" markdown="1"> … </div>    <!-- «Запомни» -->
  <div class="warn" markdown="1"> … </div>   <!-- «Частая ошибка» -->
  ```
- Названия вопросов и разделов — `_data/questions.yml`, `_data/sections.yml`.
- Вопросы теста — `assets/quiz-data.js`.

## Локальный просмотр

```bash
gem install jekyll kramdown-parser-gfm
jekyll serve
# открыть http://localhost:4000/AOS-Exam/
```
